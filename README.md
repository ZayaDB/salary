# 월급 장부

매일 사장님이 문자로 알려 준 금액을 적고, 월급날 4대보험을 뺀 뒤 계약 월급(기본 450만 원)보다 더 벌었는지 덜 벌었는지 계산하는 작은 모바일 웹앱입니다.

## 쓰는 방법

1. 처음 열면 계약 월급을 넣고 **장부 만들기**를 누릅니다.
2. 홈 또는 달력에서 하루 금액과 메모를 적습니다.
3. **정산** 탭에서 월급날 받을 돈, 더 받을 돈, 돌려줄 돈을 봅니다.
4. **설정**에서 4대보험 요율을 직접 바꿀 수 있습니다. 기본값은 2026년 근로자 부담입니다.
   - 국민연금 4.75%
   - 건강보험 3.595%
   - 장기요양: 건강보험료의 13.14%
   - 고용보험 0.9%
   - 산재보험은 사장님이 내므로 계산에 넣지 않았습니다.

로컬에서 보려면:

```bash
npm install
npm run dev
```

## Netlify에 올리기

사장님과 **같은 장부**를 보려면 사이트에 Functions가 같이 올라가야 합니다. `dist` 폴더만 드래그 앤 드롭하면 공유가 안 됩니다.

1. 이 폴더를 GitHub에 올립니다.
2. [Netlify](https://app.netlify.com)에서 **Add new site → Import an existing project**를 고릅니다.
3. 빌드 명령은 `npm run build`, 공개 폴더는 `dist`입니다. `netlify.toml`이 이미 들어 있습니다.
4. 배포가 끝나면 주소를 사장님에게 보냅니다. 설정에 있는 **공유 코드** 또는 **링크**를 같이 쓰면 됩니다.

같은 코드를 쓰는 두 사람이 장부를 같이 보고, 한쪽이 적으면 다른 쪽이 앱을 다시 열거나 화면을 다시 볼 때 맞춰집니다.

배포 전에는 이 브라우저에만 저장됩니다. 설정에서 JSON 파일로 백업한 뒤 다른 폰에서 가져올 수도 있습니다.

폰에서는 브라우저 메뉴의 **홈 화면에 추가**를 누르면 앱처럼 열립니다.
